# Credit Risk Analytics
Graduation project for the Professional Data Analysis course, built on the Home Credit Default Risk dataset.

## Project Idea
- Banks lose money when customers fail to repay their loans. This project analyzes real consumer-credit data from *Home Credit* to understand *what drives loan default* and to build a model that *predicts the probability of default* for each applicant.

## The project covers the full data workflow:

- 1. *Data modeling:* loading the related tables into a database, designing an ERD and a star schema, and joining tables with SQL.
- 2. *Data cleaning and EDA:* handling missing values and outliers, and exploring default patterns by age, income, occupation, loan type, and more.
